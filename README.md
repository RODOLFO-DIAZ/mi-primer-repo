# Mi primer repositorio

Este repositorio documenta mi aprendizaje de Git.

Autor: Rodolfo Díaz Solano

## Poema

Commit a commit,
la historia se escribe,
git nunca olvida.

## Qué aprendí

- git init crea un repositorio
- git add prepara cambios
- git commit guarda una instantánea
- git push sube el trabajo a GitHub
